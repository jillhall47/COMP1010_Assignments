## Assignments

### Assignment 1 — Coin Counter

**File:** `A1-CoinCounter.py`

This program:

- Prompts the user for their first name
- Asks for the number of quarters, dimes, nickels, and pennies
- Converts coin counts to integers
- Calculates the total monetary value in cents
- Displays the result in a descriptive sentence

Example output:

```text
Jillian, your total coin value is 263 cents.
```
